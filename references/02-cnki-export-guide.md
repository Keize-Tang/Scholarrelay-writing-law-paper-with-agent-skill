# 02 · 知网题录导出指南（人操作手册）

> 这一节是**给人看的操作步骤**。AI 在阶段 1 应当把本文档要点复述给人，并等待人回传题录文件。

## 零、为什么这一步必须由人做（先理解，再操作）

**知网对个人账号没有下载额度。** 能下载，靠的是**所在机构的订阅**，
而机构订阅的校验是三层叠加的：

| 层 | 校验什么 | 具体表现 |
|---|---|---|
| **① IP 授权** | 请求是否来自机构出口 IP | 先登录学校 **webvpn**，再在 vpn 里进知网，知网看到的就是机构 IP，于是给你下载额度 |
| **② 登录态** | 是否有有效会话 | 会话绑在真实浏览器的 cookie 上，常带设备指纹 |
| **③ 下载额度** | 当日还能下几篇 | 超限即拒，且没法预知何时触发 |

**三层里任何一层不过，你拿到的只是摘要页，不是全文。**

这就是为什么本工作流**不试图让 AI 去自动化这条链路**：

- 这不是"写个爬虫"能解决的——它本质是**访问授权**问题；
- 已有的自动化方案要求使用者自己配好浏览器环境（常驻进程、CDP 端口、
  登录态保持、验证码人工介入、被风控拦截后重试），**对非专业使用者门槛过高**；
- 而**你本来就已经登着 webvpn**——手动做完检索、导出、下载，通常只要几十秒。

> **所以分工在这里切开：人做"需要授权的那几步"，AI 做其余全部。**
> 这不是妥协，是把 AI 的算力用在它真正擅长的地方（批量阅读与写作）。

### 你只需要做三件事

1. **登录学校 webvpn**（用你自己平常的方式）
2. **在 vpn 内进入知网，检索并导出题录**（见下文第二、三节）
3. **下载 A 档文献的 PDF**，放进项目目录（见下文第四节）

做完把**题录文件**和**文件名列表**交给 AI，后面的活都由它干。

---

## 一、检索式怎么定

**核心原则：先宽后窄，三段式。**

1. **第一段：主题词**（篇关摘 TKA 或主题 SU）
   把选题拆成 2—4 个核心概念，用 `AND` 连接。例：
   - 选题"<概念A>与<概念B>的关系"→ `<概念A> AND <概念B>`（如"社区协商 AND 基层治理"）
   - 选题"<制度>的功能边界"→ `<制度> AND (审查 OR 分级 OR 许可)`（按你的研究对象替换）
   - 若研究对象是政策新概念，可先用该概念单独检索，再逐步加入限定词

2. **第二段：来源类别**（决定文献质量，务必要选）
   - 法学/社科优先勾选：**CSSCI**、**北大核心**
   - 学位论文、会议论文一般排除，除非选题极新、期刊文献不足
   - ⚠️ 若选题是近年才出现的新概念，早期文献必然很少，此时**可放宽到全部来源**，但要靠阶段 2 的分级把质量关

3. **第三段：时间范围**
   - 一般取近 5—10 年；**经典文献（1990s—2000s 的奠基性论文）不要因为年份被筛掉**，它们常在"理论溯源"处不可替代。
   - 若选题有明确的政策节点（如某年新法修订），可分两次检索：一次全时段，一次限定节点后。

**检索字段优先级**：篇关摘(TKA) → 主题(SU) → 关键词(KY) → 篇名(TI)。
TKA 最全但噪声多，TI 最准但漏检多。建议以 TKA 为主检索，再用 TI 做补充。

## 二、导出题录（关键步骤）

1. 在检索结果页**勾选**要保留的文献（可翻页累积勾选，或"全选本页"后翻页继续）。
2. 点击结果列表上方的 **「导出与分析」→「导出文献」**。
3. 导出格式二选一：

| 格式 | 长什么样 | 适合 |
|---|---|---|
| **RefWorks** | 每行以 `RT Journal Article`、`A1 作者`、`T1 标题` 开头 | 字段干净，推荐 |
| **EndNote** | 每行以 `%0 Journal Article`、`%A 作者`、`%T 标题` 开头 | 兼容性最好 |

> 本技能的两个脚本（`parse_cnki.py` / `cnki2gbt.py`）**自动识别这两种格式**，随便选哪个都行。选你顺手的那一个。

4. 点击「导出」→ 得到 `CNKI-<时间戳>.txt`（如 `CNKI-20260827143104583.txt`）。
5. **把这个 txt 放进论文项目根目录**，不要改名——文件名里的时间戳正好标识了检索批次。

> ⚠️ RefWorks 导出默认**不含 DOI 字段**；EndNote 导出可能含 `%R`（DOI）。参考文献最终不要留 DOI（见 06 文档），脚本会自动清理。

## 三、下载 PDF（关键步骤）

1. 在题录清单里挑出 A 档文献（详见 03 文档）——**这一步等 AI 给分级清单后再做**，不要盲下。
2. 逐篇点进详情页 → 下载 PDF。
3. 保存到**论文项目根目录**，命名规范：

   ```
   标题_第一作者.pdf
   ```

   例：`<文献标题>_<第一作者>.pdf`（标题中的空格建议改为下划线，避免命令行与脚本处理路径时出麻烦）

   > 为什么用下划线而不用空格？避免命令行和脚本处理路径时的引号地狱。

4. **每下完一批就告诉 AI 文件名列表**，AI 会核对"分级清单里的 A 档是否都到齐"。

## 四、可能遇到的问题

| 现象 | 处理 |
|---|---|
| 出现滑块验证码 | 人手动完成；AI 侧必须暂停等待，不得尝试绕过 |
| 无下载权限（校内未订阅该刊） | 换来源（读秀/超星/馆际互借），或如实标注"仅摘要参考" |
| PDF 文本层损坏、复制出来是乱码 | 用 OCR 工具转文本，把 txt 一并放进项目根目录 |
| 直链下载报"来源应用不正确(01)" | 已知问题，放弃直链，改手动逐篇下载 |
| 某一篇实在拿不到全文 | 告知 AI，AI 会把它降级为"仅摘要参考"或从引用池移出 |

## 五、EndNote / RefWorks 字段对照（供排查问题）

| 含义 | RefWorks | EndNote |
|---|---|---|
| 文献类型 | `RT` | `%0` |
| 作者 | `A1`（可多行） | `%A`（可多行） |
| 作者机构 | `AD` | `%+` |
| 标题 | `T1` | `%T` |
| 期刊名 | `JF` | `%J` |
| 年 | `YR` | `%D` |
| 卷 | `vo` | `%V` |
| 期 | `IS` | `%N` |
| **起止页码** | `OP` | `%P` |
| 关键词 | `K1` | `%K` |
| 摘要 | `AB` | `%X` |
| ISSN | `SN` | `%@` |
| 国内刊号 | `CN` | `%L` |
| 链接 | `LK` | `%U` |
| DOI | `DO` | `%R` |

> **注意**：`%P` / `OP` 就是审稿人常说的"缺起止页码"的答案所在。从题录里能自动补全，**所以千万不要手工编页码**。
