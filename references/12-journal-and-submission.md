# 12 · 选刊、投稿与检查清单

> 论文写好只是第一步。**投错刊物 = 白写。** 这一章解决"投哪里、怎么投、投前查什么"。
> 内容针对中文法学期刊生态；学位论文答辩与英文期刊的差异在文末另列。

---

## 一、先想清楚：你要的是什么

投稿前必须回答一个问题——**这次投稿的目标是什么？**

| 目标 | 策略 | 代价 |
|---|---|---|
| **获奖 / 被录用（成功率优先）** | 选与选题层级匹配的刊物，接受"降级投" | 刊物层级可能低于预期 |
| **冲高（含金量优先）** | 冲 CSSCI，接受高退稿率 | 时间成本高，可能需要多轮改投 |
| **赶时间（截止日期优先）** | 选审稿周期短、反应快的刊物 | 刊物层级与周期不可兼得 |

**这个判断必须由人做出，AI 只能提供信息。** 因为它取决于你的时间预算、投稿历史、以及这篇稿子在你作品序列里的位置。

> ⚠️ 一个常见错误：拿一篇适合专业刊的稿子去投综合刊，或反之。
> **专业刊看重选题的纵深，综合刊看重问题的一般性。** 详见下文"按研究方法匹配"。

## 二、期刊梯队与选题匹配

### 梯队划分（法学期刊生态）

中文法学期刊大致分四层：

| 梯队 | 特征 | 投稿难度 |
|---|---|---|
| **第一层：法学核心（CSSCI 法学类）** | 《中国法学》《法学研究》《中外法学》《清华法学》《法商研究》《政法论坛》《法制与社会发展》《法学》《政治与法律》《比较法研究》《环球法律评论》《法学家》等 | 极高，多要求博士学位或副高以上 |
| **第二层：CSSCI 扩展版 / 综合刊法学栏目** | 各高校学报哲社版的法学栏目、部分专业刊 | 高，但接受硕士生独立署名 |
| **第三层：普通专业刊 / 行业刊** | 部门法专业期刊、行业系统刊物、工会／劳动领域刊群 | 中，较为友好 |
| **第四层：会议论文集 / 征文 / 集刊** | 学术年会征文、论坛征文、以书代刊的集刊 | 相对友好，是学生作者的主要发表通道 |

> **对学生作者最现实的两条路**：① 面向学界的**征文比赛**（有获奖机制，不占用期刊版面）；
> ② **第三层专业刊 / 行业刊**（看重选题的实务相关性，对作者身份更宽容）。

### 按研究方法匹配

| 你的论文是 | 优先投 |
|---|---|
| 概念辨析、思想史 | 综合刊、法理／法史专业刊 |
| 法教义学、规范分析 | 部门法核心刊、专业刊 |
| 案例实证、数据分析 | 实证法学类刊物、专业刊 |
| 政策／制度研究 | **行业刊、实务刊**（如劳动、工会、社保系统刊群） |
| 比较法 | 有比较法栏目的综合刊 |

### 按部门法匹配

部门法论文优先投对应部门法刊物或综合刊的对应栏目。
**跨部门法的选题**（如"平台用工 + 社会保险 + 财税法"）宜投综合刊或与该选题最直接相关的专业刊。

> ⚠️ **选题敏感度提示**：涉及意识形态、领导人论述、党的制度建设等选题，
> 匹配的是**党建／思想政治类刊物或综合刊的相关栏目**，
> 不能用纯法学规范分析的框架硬投法学核心刊。

## 三、投稿纪律

### 1. 一次一投（底线）

**同一时间只投一家。** 一稿多投是学术不端，一旦被发现会被刊物拉黑。

### 2. 梯次降投

退稿后按梯队逐级下调，不要跳级。
每次降投前**根据新刊物调整形式**：篇幅、引注体例、摘要长度、栏目匹配度。

### 3. 退稿后先改再投

**收到退稿意见不等于失败，是免费的审稿。**
先按意见修订，再投下一家——否则同样的问题会被第二家审稿人再抓一次。

> ⚠️ 但如果退稿**没有给任何意见**（常见于初审直接退），说明问题可能在选题层级不匹配，
> 此时应优先换刊而非改文。

### 4. 专题征稿是机会

期刊／会议常发布专题征稿（Call for Papers）。**专题征稿的录用率通常高于常规投稿**，
因为编辑有确定的组稿需求。值得定期关注目标刊物的官网与公众号。

## 四、审稿人视角：他们怎么看你

### 编辑初审（决定送不送外审）

编辑在几分钟内判断四件事：

1. **选题合不合本刊的路子**（最重要，不合直接退）
2. **摘要有没有把结论说出来**（见 `10-abstract-and-title.md`）
3. **格式对不对**（引注体例、篇幅）
4. **作者身份**（部分刊物有硬门槛）

**编辑初审最常直接退稿的原因是"不合本刊选题范围"，而不是质量问题。**

### 外审专家评估维度

| 维度 | 专家在想什么 |
|---|---|
| 问题重要吗 | 这是真问题吗，还是自造问题？ |
| 有没有新意 | 比既有研究多说了什么？ |
| 论证扎实吗 | 论据够不够，逻辑有没有跳步？ |
| 文献全不全 | 该引的重要文献引了吗？有没有漏掉关键对手？ |
| 有立场吗 | 作者到底主张什么？还是和稀泥？ |
| 读得懂吗 | 结构清楚吗，语言是否空转？ |

### 外审常见负面意见（提前自查）

- 「问题意识不明确」→ 核心论题没有一句话锁死（见 `09-revision-discipline.md`）
- 「与既有研究区分度不足」→ 文献综述没做到"有洞见"
- 「论证跳跃」「结论先于证据」→ 论证链条有断点
- 「文献综述流于罗列」→ 只梳理不评价
- 「概念使用不统一」→ 同义词循环（见 `11-de-ai-patterns.md`）
- 「学术规范不严」→ 引注缺页码、事实错误（见 `06`、`05`）

## 五、投稿前检查清单

### 内容层

- [ ] 核心论题能用一句话说清，且全文围绕它展开？
- [ ] 摘要把**结论**说出来了（不只是背景和问题）？
- [ ] 关键词是 4—5 个通行术语，无自创概念？
- [ ] 文献综述做到了"全面、准确、公允、有洞见"四条？
- [ ] 有明确立场，不是一味平衡？
- [ ] 结论有回扣论点、指出局限、给出后续方向？

### 证据层

- [ ] 法条核对过**现行有效版本**与条号？（新旧法条号变化是高频硬伤）
- [ ] 案例的**编号／当事人／裁判要点**三者一致？
- [ ] 所有数据都标注了**时点与来源**？
- [ ] 没有地方数据与国家数据混用？
- [ ] 没有引用未读原文的文献？
- [ ] 政策文件都带**文号**并已列入参考文献？

### 规范层

- [ ] `validate.py` 通过（无缺失／多余／跳号／重号／顺序不符）？
- [ ] 期刊文献都有**起止页码**？
- [ ] 网络来源有发布日期 + 引用日期 + 网址？
- [ ] 引注体例符合**目标期刊**要求（页下脚注 or 文末列表）？
- [ ] 无 DOI 残留？

### 形式层

- [ ] 篇幅符合刊物要求？
- [ ] 标题层级不超过两级，副标题有必要才留？
- [ ] 正文无粗体强调（法条、案例名除外）？
- [ ] 段落长度有变化，不是均匀的 200—300 字？
- [ ] 小标题反映具体论点，不是模板？
- [ ] `aitrace.py` 扫描无严重项？
- [ ] 作者信息、单位、联系方式已填全？

### 投递层

- [ ] 只投了这一家？
- [ ] 按刊物要求做了**匿名处理**（如需匿名审稿）？
- [ ] 文件名规范，不含个人信息（如需匿名）？
- [ ] 投稿系统字段填写完整？

## 六、其他场景

### 会议征文 / 论坛投稿

- 通常有**确定的议题列表**，务必对照议题调整切入角度（"对应议题X"）。
- 投稿截止日期是**硬约束**，倒排时间：排版留 3 天，自审留 2 轮。
- 会议论文常限定篇幅（如 12000—15000 字），比期刊更宽松。

### 学位论文答辩前

在上述清单基础上追加：
- [ ] 结构完整（绪论／文献综述／主体章节／结论／参考文献／致谢）？
- [ ] 章节字数分布合理，无头重脚轻？
- [ ] 创新点表述克制，经得起答辩追问？
- [ ] 已准备答辩 PPT 与可能的追问清单？

### 英文期刊 / SSCI

- 语言质量是硬门槛，建议专业润色。
- 引注体例用目标期刊的（多为 APA / Bluebook / OSCOLA）。
- Cover Letter 要点：选题与刊物的契合度、核心贡献、作者背景。
- 匿名审稿要求更严格，正文与文件属性都要去标识。
