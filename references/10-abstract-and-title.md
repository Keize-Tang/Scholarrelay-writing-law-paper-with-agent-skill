# 10 · 标题、摘要与关键词

> 这三样是**编辑决定要不要送外审**的第一道关。摘要写砸，正文再好也进不了外审。
> 法学核心期刊的摘要规范与一般学科差别很大，最容易踩的是"本文"二字。

---

## 一、摘要

### 硬性规范

| 项 | 要求 |
|---|---|
| 字数 | **200—300 字**（不含关键词） |
| 段落 | **单段，不分段** |
| 句式 | **全部陈述句**，不用疑问句、感叹句 |
| 人称 | **零人称**——不用"笔者""本文" |
| 内容取舍 | 只留核心问题、主要原因、关键对策；删掉文献回顾、研究方法、次要数据 |

### ⚠️ 绝对禁止「本文」

这是法学期刊与一般学科最显著的区别。**摘要里出现"本文"，编辑会直接扣印象分。**

不要写："本文认为……""本文试图论证……""本文旨在……"

改用这四种开头方式：

| 方式 | 示例 |
|---|---|
| 直接陈述研究对象 | 「追缴、责令退赔、返还和没收是刑事涉案财物处置的四大措施。」 |
| 以现象／制度为主语 | 「我国刑事涉案财物处置程序的相关规定呈现出明显的碎片化特征。」 |
| 以价值判断开头 | 「准确界定刑事涉案财物的概念，对于规范查封、扣押、冻结程序具有重要的现实意义。」 |
| 以事实陈述开头 | 「与传统的定罪证明相比，涉案财物的证明具有较强特殊性。」 |

### 三段论结构

摘要是全文论证的压缩，必须走完「问题 → 分析 → 对策」三段：

| 层次 | 功能 | 常用表述 |
|---|---|---|
| **问题层** | 指出研究对象存在的问题／困境／特征 | 「呈现出……特征」「……存在……问题」「……面临……困境」 |
| **分析层** | 揭示问题的根源 | 「根源在于」「主要症结在于」「问题根源于」 |
| **对策层** | 提出方案／制度建议 | 「对此，应当……」「有必要……」「建议以……为着力点」 |

**常见毛病**：只有问题层和对策层，缺分析层。于是摘要读起来像"有个问题，所以要改"——
**分析层才是学术贡献所在**，不能省。

### 摘要自查清单

- [ ] 字数在 200—300 字之间？
- [ ] 单段、不分段？
- [ ] 没有出现"本文""笔者""本人"？
- [ ] 全部是陈述句？
- [ ] 问题 → 分析 → 对策 三段完整？（尤其别丢"分析层"）
- [ ] 没有堆砌"具有深远意义"这类空话？（见 `11-de-ai-patterns.md`）
- [ ] 与引言的第一段不重复？

### 摘要 ≠ 引言

| | 摘要 | 引言 |
|---|---|---|
| 面向 | 不读全文的读者（编辑、检索者） | 读了摘要、准备读全文的人 |
| 内容 | 浓缩全文核心观点（含结论） | 交代背景、问题意义、方法、结构 |
| 能否给结论 | **必须给** | 通常不给，只提问题 |

**常犯错**：把引言压缩成摘要——只讲背景和问题，不讲结论。摘要必须把**答案**说出来。

## 二、标题

### 两条原则

1. **标题要反映具体论点，不要用模板**。
   「问题的提出」「XX 制度的完善路径」这类标题在几百篇论文里都出现过，编辑一眼就滑过去了。
   ✅ 好标题：「XX 条文的解释路径争议」「从 XX 案看 XX 条款的适用边界」「比较法视野下的 XX 制度完善」

2. **标题层级最多两级**（主标题 + 一个破折号副题）。
   三层标题（主—副—再副）说明作者还没想清楚要说什么。

### 标题自查

- [ ] 能否从标题看出本文的**具体判断**，而不只是研究范围？
- [ ] 有没有用"初探""浅析""刍议"这类自贬词？（学术论文不宜自贬）
- [ ] 副标题是否真的必要？（能删就删）
- [ ] 标题里的概念，正文是否都作了界定？

## 三、关键词

### 规范

- **4—5 个**实体性名词短语
- 第一个是研究对象的**核心概念**
- 覆盖"概念层 → 制度层 → 理论层"的梯度
- 关键词之间要有逻辑关联

### ⚠️ 不要用自创概念作关键词

真实踩过的坑：某稿把自创的定位概念（形如"准××制度"）放进关键词。
问题是——**关键词是别人用来检索你的词**，自创概念没人会拿它去搜，检索价值为零。

> 自创概念的价值在于正文里"立"它，不在于关键词里"标"它。
> 关键词应当回归通行术语。

**改法示例**：
- ❌ 「<研究对象>；<场景>；<机制>；**<自创概念>**；<上位概念>」
- ✅ 「<研究对象>；<场景>；<机制>；<通行上位概念>；<相关制度>」（把自创概念换成通行术语）

同理，**含义过泛的词也不宜作关键词**（如一个涵盖面极广的上位概念，宜换成更具体的研究对象或机制）。

### 关键词自查

- [ ] 4—5 个？
- [ ] 第一个是核心概念？
- [ ] 全是通行术语，没有自创概念？
- [ ] 有人真的会用这些词来检索本文吗？

## 四、生成摘要的工作流程

1. **读全文**（不是读提纲）——提取：核心研究问题、论证路径、关键判断或制度建议、重要实证数据。
2. **按模板搭骨架**：
   > [问题句] 指出制度缺陷或实践困境，点明研究对象。
   > [分析句] 揭示深层原因，或分析既有方案的不足。
   > [对策句] 提出具体方案，以"应当""建议""有必要"引导。
   > [目标句] 收束规范目标（可选，字数允许时）。
3. **压缩到 200—300 字**：删铺垫句、删过渡句、用动词短语替代从句、合并重复意思。
4. **过一遍自查清单**（上方）。

> **注意**：AI 生成的摘要天然偏长、偏虚、爱用"本文"。
> 写完必须逐条过 `11-de-ai-patterns.md` 的清单。
