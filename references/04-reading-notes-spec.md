# 04 · 文献精读笔记规范

## 笔记的定位（最重要的一句话）

> **笔记是检索索引，不是引用依据。**
>
> 每一份精读笔记的开头都必须写死这句话。正文引用前，**必须回读原文对应页核验**。

原因很实在：精读笔记是 AI 从 PDF 提炼的二手材料。如果写作时直接根据笔记复述"某某认为……"，就等于**基于转述做转述**，误差会累积，最终可能变成编造。

## 必备要素

| 要素 | 说明 |
|---|---|
| 选题 | 本文选题（防止笔记与项目错配） |
| 精读范围 | 下载了多少篇 PDF，其中多少可用，哪些文本损坏及如何处理 |
| 精读日期 | 便于判断时效 |
| **用途声明** | 固定写"**正文引用前须定向回读原文核验，本笔记仅作检索索引**" |

## 两种组织方式（按需选用）

### 方式一：按"可引用的原句"组织（适合核心章）

这是**主力格式**。适合需要大量直接引用的论文。

```markdown
## 核心论断速查（按论点归类）

### 支撑论点①：公映许可只审查"内容安全"，不承担艺术质量把关

| 文献 | 可直接引用句 | 出处 |
|---|---|---|
| 贾磊磊.用标尺取代剪刀[J].艺术百家,2005(5) | "审查委员会发放的实质上是一部电影进入市场的'通行许可证'。它的首要职责是……而不是对它的美学意义做判断" | 第4页 |
| 詹庆生.审查还是分级?[J].电影艺术,2012(2) | "审查遵循的是'是－否'的过滤机制，它最终必然表现为授权－禁止、批准－不批准、通过－不通过的二元结果" | 第2页 |
```

**关键点**：
- 引用句必须**逐字**取自原文，不得改写、不得拼接
- 必须标**页码**（PDF 页码或刊物页码，注明是哪一种）
- 引用句用引号包住，避免日后分不清"这是原话还是我的概括"

### 方式二：按"单篇"组织（适合需要把握全篇立场的文献）

```markdown
### 3. 李四《示例制度的规范构造与适用》
- 出处：《示例法学》2024年第3期，第669-689页。某大学某学院教授。国家社科基金项目（示例编号）。
- 核心观点：
  - 工伤保险系基于**人格从属性**建立的雇主责任险；"新职伤"法理障碍是劳动关系
  - **生活保障费争议**：按最低工资标准发放"似欠缺乏法理依据"，应结合事故发生前收入水平核定
  - 制度定位：该制度应与既有制度衔接，长期看规则统一是大势所趋
- **对本文的用途**：
  - 第一章：按单缴费的法理基础（经济从属性）
  - 第二章：生活保障费"缺乏法理依据"——直接支撑"同构不同价"论点
  - 第四章：待遇核定标准建议
```

**关键点**：
- "对本文的用途"必须**分章列出**，这是笔记能被高效检索的核心
- 作者单位要记（用于判断学术谱系、是否为目标期刊作者）
- 基金项目要记（用于判断权威性）

## 实战经验：两种格式可以叠加

一个项目里常见的做法是：
- 用**方式一**处理 A 档里承担核心论证那 10—20 篇；
- 用**方式二**处理其余 A 档与重要 B 档；
- 文末单开一节 **「分章节文献地图」**，把文献按论文章节重新索引一遍，写作时按章调取。

## 专门的"引用注意"栏目

每份笔记末尾都应有这一节，记录**口径陷阱**。实例：

```markdown
## 写作纪律与引用注意

1. **逐字引用**：上表摘录句均已逐字取自文本，但正文引用前仍须定向回读原文对应页核验
   （尤其页边 OCR 页码可能有 ±1 页误差）。
2. **旧法语境标注**：孔祥俊1998（旧反法）、蒋志培2007（旧法第9条）——引用时注明
   "现行《反不正当竞争法》第8条承继/修改"。
3. **类比限定**：商品房/金融/食品案例与电影存在"可验证性"差异，引用时须限定为
   "可客观核验的事实性承诺"，避免把艺术质量评价纳入欺诈。
4. **立场分歧提示**：高志宏（故意或重大过失均可）vs 迟颖/潘俊（要求故意与错误认识）
   ——论文宜采高志宏立场，以肖顺武谦抑性回应"过度扩张"质疑。
5. **文本损坏**：宋亚辉《现代规制工具进入新广告法》（社会科学报）文本编码损坏不可用，
   **不引用**；需补该论据时用 W18 替代。
```

第 5 条尤其重要：**读不了的文献要明确记录"不引用"，不要把它留在池子里当定时炸弹。**

## 补充精读的处理

写作中追加的文献（往往由人临时提供）单独开一节：

```markdown
## 补充精读（2026-08-28，规制工具理论）

### W49 应飞虎.消费者立法中的信息工具[J].现代法学,2019,41(2):119-136
- 核心：信息工具=运用信息解决问题的公权规制方式
- 关键论断：
  - "在所有规制工具中，信息工具对交易的干预最为浅度……作为一种亲市场的规制工具，
    在解决信息问题的过程中首先需要被选择"（第126页）
- 用途：第四章（一）理论支柱
- **引用注意：优势须与功能限度成对引用**；消费者法语境移植到电影场景须自行论证信息不对称
```

注意最后一行的"引用注意"——**防止为了论证而片面引用**。这是学术诚信的细活。
