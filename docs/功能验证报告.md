## 六、已知边界（诚实说明）

1. **工具是定位器，不是裁判**：`redundancy` / `aitrace` 只负责把可疑处找出来，
   是否修改由人看上下文决定。实测已发表论文中逾 100 字的句子占 6%、最长 198 字，
   属正常文风，故阈值已按作者基线校准。
2. **标题编号体系不是硬规则**：已发表论文中阿拉伯与中文体系 **2:2**，取决于目标期刊；
   工具只报告当前体系并提示核对稿约，唯一硬性要求是全篇不混用。
3. **引用真实性无法自动核验**：工具只能校验"编号与列表是否对应"，
   不能判断某篇文献是否真的支持某句话——那是人的职责（见 `05-writing-discipline.md`）。
4. **自动扫描不能替代人工通读**：`check_pii.py` 只抓模式化信息，
   可推断身份的组合信息需要人工判断。
